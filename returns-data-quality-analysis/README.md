# Product Returns and Data Quality Analysis

Cleans an order dataset and investigates return rates, delivery time and common return reasons. Deliberate missing and duplicate records demonstrate basic quality checks. The data is synthetic.

## Business questions
- Which categories have the highest return rates?
- What reasons drive returns?
- Are duplicates or missing values affecting the analysis?

## Tools and skills
Python, Pandas, Matplotlib, data cleaning, duplicate detection, missing-value checks, root-cause analysis.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Windows executable
Double-click `Run_Returns_Data_Quality_Analysis.exe`. No Python installation is required. When it finishes, press Enter and open the `outputs` folder.
