# Executive KPI Report

Builds a concise management scorecard for revenue, orders, conversion and customer satisfaction, then compares the latest month with the previous month. The data is synthetic.

## Business questions
- Are revenue and orders improving?
- Is conversion becoming more efficient?
- Are commercial gains supported by customer satisfaction?

## Tools and skills
Python, Pandas, Matplotlib, KPI reporting, month-over-month analysis, executive communication, data visualisation.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Windows executable
Double-click `Run_Executive_KPI_Analysis.exe`. No Python installation is required. When it finishes, press Enter and open the `outputs` folder.
