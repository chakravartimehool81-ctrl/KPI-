# Retail Sales Performance Dashboard

A beginner-friendly retail analytics project inspired by the business-question and visual-storytelling work in the Tata Data Visualisation job simulation. It uses a synthetic dataset, not confidential company data.

## Business questions
- How does revenue change month by month?
- Which regions and product categories generate the most revenue?
- Where should management focus sales planning?

## Tools and skills
Python, Pandas, Matplotlib, data cleaning, KPI calculation, trend analysis, data visualisation.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

Outputs are saved in `outputs/`, including the dashboard image and summary CSV files.

## Windows executable
Double-click `Run_Retail_Sales_Analysis.exe`. No Python installation is required. When it finishes, press Enter and open the `outputs` folder.
