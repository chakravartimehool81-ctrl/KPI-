# Regional Demand and Expansion Analysis

Compares order demand, conversion and customer ratings across Indian regions to identify attractive expansion opportunities. The data is synthetic.

## Business questions
- Which region has the strongest demand?
- Where are conversion rates highest?
- Which region ranks highest on a simple expansion opportunity score?

## Tools and skills
Python, Pandas, Matplotlib, regional analysis, KPI design, ranking, business recommendations.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Windows executable
Double-click `Run_Regional_Demand_Analysis.exe`. No Python installation is required. When it finishes, press Enter and open the `outputs` folder.
