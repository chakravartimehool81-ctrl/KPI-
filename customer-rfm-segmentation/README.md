# Customer RFM Segmentation

Segments customers using Recency, Frequency and Monetary value so a marketing team can design targeted retention campaigns. The transaction data is synthetic.

## Business questions
- Who are the most valuable customers?
- Which customers are at risk of becoming inactive?
- How large is each actionable customer segment?

## Tools and skills
Python, Pandas, Matplotlib, customer analytics, RFM scoring, segmentation, data storytelling.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Windows executable
Double-click `Run_Customer_RFM_Analysis.exe`. No Python installation is required. When it finishes, press Enter and open the `outputs` folder.
